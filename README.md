## 本地预览

这是纯静态网站，无需安装依赖或构建。在仓库根目录运行：

```sh
python3 -m http.server 8000
```

然后打开 `http://localhost:8000/`。

## 部署

可部署到 GitHub Pages、Netlify 或任何静态网站主机。GitHub Pages 的发布来源选择 `main` 分支的根目录即可。所有内部页面和资源均使用相对路径，支持部署在仓库子目录下。
